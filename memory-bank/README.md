# Memory Bank

Active context for coding agents. This is not static documentation.

## Purpose

The memory bank stores project context that agents must read before coding:

- Business context
- Technical context
- Active project rules
- Current status and recent decisions

## Maintenance Rules

1. Update after meaningful technical or product changes.
2. Keep entries specific and verifiable.
3. Record decisions and rationale, not just outcomes.
4. If context changes, old assumptions must be replaced.

## Required Files

- `business-context.md`
- `technical-context.md`
- `project-rules.md`
- `current-status.md`

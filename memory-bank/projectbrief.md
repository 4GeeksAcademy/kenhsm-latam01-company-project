# Project Brief

## Negocio

Brasaland es una cadena de 14 restaurantes que opera en Colombia y Florida, con ~115 personas y una operacion distribuida en dos monedas (COP/USD). La marca necesita crecer sin perder consistencia de servicio ni calidad culinaria.

## Objetivos del proyecto

1. Construir interfaces visibles desde el dia uno para clientes (website) y equipos internos (backoffice).
2. Estandarizar una forma de trabajo con agentes de codigo basada en memoria persistente, reglas y skills reutilizables.
3. Preparar la base para servicios backend centralizados en `services/`.
4. Alinear cada entrega con necesidades reales de operaciones, compras, marketing, RRHH, formacion y direccion ejecutiva.

## Problema que resuelve

Actualmente, gran parte de la operacion se gestiona con herramientas manuales (Excel, WhatsApp, procesos no integrados). Esto limita visibilidad en tiempo real, dificulta decisiones y aumenta errores operativos. El proyecto busca crear una base tecnica y de proceso para evolucionar hacia una operacion digital moderna, verificable y escalable.

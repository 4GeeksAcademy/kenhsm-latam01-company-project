# Milestone 2 Utilities

This folder contains the TypeScript implementation for milestone 2, aligned with Brasaland business context.

## File structure

- `types/models.ts`: domain interfaces and helper methods
- `utils/collections.ts`: filtering, sorting, and grouping functions
- `utils/search.ts`: linear and binary search implementations
- `utils/transformations.ts`: aggregation and reporting functions
- `utils/validations.ts`: business data validation rules

## Local TypeScript validation

Run this command from `apps/talent-pipeline-tracker`:

```bash
npx tsc --noEmit
```
